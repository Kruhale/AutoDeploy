# REST API — AutoDeploy

Documentation for the backend REST endpoints. There are three ways to explore the API:

- **This guide**: the main endpoints with real `curl` examples.
- **Swagger UI**: `https://<host>/swagger-ui.html` — interactive UI generated by springdoc-openapi from the controller annotations. Lets you execute requests from the browser.
- **OpenAPI JSON**: `https://<host>/v3/api-docs` — full schema for generating clients.

## Conventions

### `ApiResponse<T>` wrapper

**Every** endpoint returns an object with this shape:

```json
{
  "success": true,
  "message": "Descriptive text",
  "data": { /* typed payload */ }
}
```

For handled errors (`BadRequestException`, `ResourceNotFoundException`), `success=false`, `message` carries the reason and `data=null`.

### Authentication

All endpoints **except** the public ones require a header:

```
Authorization: Bearer <jwt-token>
```

The token is obtained from the login endpoint and expires after 24 h (`autodeploy.jwt.expiration=86400000` ms).

**Public endpoints** (no JWT, see `SecurityConfig`):

- `POST /api/usuarios/registro`
- `POST /api/usuarios/login`
- `GET  /api/estado/**`
- `POST /api/webhooks/git/{token}`
- `GET  /swagger-ui/**`, `/v3/api-docs/**`, `/actuator/**`
- `GET  /ws/**` (WebSocket handshake)

Calling a protected endpoint without a token returns `403 Forbidden`.

### Response codes

| Code | Meaning |
|--------|-------------|
| 200 OK | Successful operation |
| 201 Created | Resource created (creation POST) |
| 204 No Content | Successful deletion |
| 400 Bad Request | Validation failure or business rule violation |
| 401 Unauthorized | Invalid or expired JWT token |
| 403 Forbidden | Missing token or insufficient permissions |
| 404 Not Found | Resource does not exist |
| 500 Internal Server Error | Unexpected exception |

## Main endpoints

### Authentication

#### `POST /api/usuarios/registro` (public)

Creates a new user on the `free` plan.

> Build the body with jq so credentials never end up as literals in your shell history.

```bash
# non-committable placeholder: use your own password
BODY=$(jq -n --arg n Demo --arg e demo@test.com --arg p YOUR_PASSWORD \
  '{nombre:$n, email:$e, password:$p}')
curl -s -X POST https://autodeploy.kruhale.com/api/usuarios/registro \
  -H "Content-Type: application/json" \
  -d "$BODY"
```

**Response 201:**

```json
{
  "success": true,
  "message": "Usuario registrado",
  "data": {
    "id": "6a0a0a689356a752b06489e7",
    "nombre": "Demo",
    "email": "demo@test.com",
    "token": null,
    "plan": "free",
    "fechaFinSuscripcion": null,
    "idioma": "es"
  }
}
```

**Errors:** 400 if the email already exists.

#### `POST /api/usuarios/login` (public)

Returns the JWT.

```bash
# placeholder: replace YOUR_PASSWORD with the real one
BODY=$(jq -n --arg e demo@test.com --arg p YOUR_PASSWORD '{email:$e, password:$p}')
curl -s -X POST https://autodeploy.kruhale.com/api/usuarios/login \
  -H "Content-Type: application/json" \
  -d "$BODY"
```

**Response 200:**

```json
{
  "success": true,
  "message": "Login correcto",
  "data": {
    "id": "6a0a0a689356a752b06489e7",
    "nombre": "Demo",
    "email": "demo@test.com",
    "token": "eyJhbGciOiJIUzM4NCJ9.eyJzdWIiOiI2YTBhMGE2OD...",
    "plan": "free",
    "idioma": "es"
  }
}
```

**Errors:** 400 if the credentials are wrong.

### System status

#### `GET /api/estado` (public)

Consumed by the frontend's status page and by external monitoring.

```bash
curl -s https://autodeploy.kruhale.com/api/estado | jq
```

**Response 200:**

```json
{
  "success": true,
  "message": "OK",
  "data": {
    "estadoGeneral": "UP",
    "actualizadoEn": "2026-05-18T12:47:34.817564426Z",
    "servicios": [
      { "clave": "api", "estado": "UP", "descripcion": "Operativo" },
      { "clave": "baseDeDatos", "estado": "UP", "descripcion": "Operativo" },
      { "clave": "websocketTerminal", "estado": "UP", "descripcion": "Operativo" },
      { "clave": "websocketMetricas", "estado": "UP", "descripcion": "Operativo" },
      { "clave": "websocketNotificaciones", "estado": "UP", "descripcion": "Operativo" },
```

### VPS servers

#### `GET /api/servidores` (requires JWT)

Lists the servers owned by the logged-in user.

```bash
TOKEN="eyJhbGciOi..."
curl -s https://autodeploy.kruhale.com/api/servidores -H "Authorization: Bearer $TOKEN" | jq
```

**Response 200:**

```json
{
  "success": true,
  "message": "OK",
  "data": [
    {
      "id": "6a09f4f59356a752b064885a",
      "nombre": "test-vps",
      "direccionIp": "10.0.0.5",
      "puertoSsh": 22,
      "usuarioSsh": "autodeploy",
      "metodoAutenticacion": "password",
      "estado": "conectado",
      "fechaCreacion": "2026-05-17T17:03:49"
    }
  ]
}
```

#### `POST /api/servidores` (requires JWT)

Registers a new server. The password/private key is encrypted with AES-256 before being stored.

```bash
# placeholder: replace YOUR_SSH_PASSWORD with the remote server's real one
BODY=$(jq -n \
  --arg n prod-api --arg ip 1.2.3.4 --arg u root --arg pw YOUR_SSH_PASSWORD \
  '{nombre:$n, direccionIp:$ip, puertoSsh:22, usuarioSsh:$u,
    metodoAutenticacion:"password", password:$pw}')
curl -s -X POST https://autodeploy.kruhale.com/api/servidores \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d "$BODY"
```

**Response 201:** The created server, with the password already encrypted in `passwordCifrada`.

#### `POST /api/servidores/probar-conexion` (requires JWT)

Tests the SSH connection before saving.

#### `POST /api/servidores/{id}/reboot` (requires JWT)

Runs `sudo reboot` over SSH.

### Deployments

#### `POST /api/deploy/git` (requires JWT)

Deployment via git clone/pull on the VPS.

```bash
curl -s -X POST https://autodeploy.kruhale.com/api/deploy/git \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "servidorId": "6a09f4f59356a752b064885a",
    "repoUrl": "https://github.com/usuario/repo.git",
    "directorio": "/var/www/miapp",
    "rama": "main",
    "tecnologia": "nodejs"
  }'
```

**Response 201:** The `Despliegue` includes a `tokenWebhook` (24 random bytes, Base64-encoded) used later to configure auto-deploy webhooks.

#### `POST /api/deploy/zip` (requires JWT, multipart)

Uploads a ZIP and deploys it over SFTP.

```bash
curl -s -X POST https://autodeploy.kruhale.com/api/deploy/zip \
  -H "Authorization: Bearer $TOKEN" \
  -F "servidorId=6a09f4f59356a752b064885a" \
  -F "directorio=/var/www/miapp" \
  -F "tecnologia=estatica" \
  -F "archivo=@/local/path/miapp.zip"
```

Limit: 50 MB. Uploading more returns 400 with "El ZIP excede el tamano maximo de 50 MB". If the file is not a `.zip`, 400. If the archive is corrupt or attempts zip-slip (`../../etc/passwd`), 400.

#### `POST /api/webhooks/git/{tokenWebhook}` (public)

GitHub/GitLab hits this endpoint on push. AutoDeploy verifies:

1. That the `tokenWebhook` matches an existing deployment.
2. That the `X-GitHub-Event: push` or `X-Gitlab-Event: Push Hook` header is present.
3. That the branch in the payload matches the configured one.

If everything checks out, it triggers `git pull` on the server.

```bash
# manual simulation (what GitHub would send)
curl -s -X POST https://autodeploy.kruhale.com/api/webhooks/git/abc123def456 \
  -H "Content-Type: application/json" \
  -H "X-GitHub-Event: push" \
  -d '{"ref":"refs/heads/main","commits":[]}'
```

### AI assistant (Pro / Business plans only)

#### `POST /api/asistente-ia/mensaje` (requires JWT)

Sends a message to the AI model. If it proposes a command, the response flags it for confirmation.

```bash
curl -s -X POST https://autodeploy.kruhale.com/api/asistente-ia/mensaje \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "usuarioId": "6a0a0a689356a752b06489e7",
    "servidorId": "6a09f4f59356a752b064885a",
    "mensaje": "Dime el uso de disco",
    "historial": []
  }'
```

**Response 200:**

```json
{
  "success": true,
  "message": "Respuesta generada",
  "data": {
    "respuesta": "Para verificar el espacio libre, ejecuto df -h.",
    "comandoPropuesto": "df -h",
    "razonamiento": "df -h muestra uso del disco en formato legible.",
    "requiereConfirmacion": true,
    "salidaComandoAutoEjecutado": null
  }
}
```

**Errors:**
- 400 "El asistente IA solo esta disponible en planes Pro y Business" (free plan)
- 400 "No has configurado tu API key de OpenRouter" (missing configuration)
- 400 "Tu API key de OpenRouter no es valida" (401 from OpenRouter)
- 400 "No tienes creditos en OpenRouter" (402 from OpenRouter)
- 400 "Demasiadas peticiones" (429 from OpenRouter, rate limit)

#### `POST /api/asistente-ia/ejecutar` (requires JWT)

Confirms and executes the proposed command.

```bash
curl -s -X POST https://autodeploy.kruhale.com/api/asistente-ia/ejecutar \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"servidorId":"...","comando":"df -h"}'
```

**Response 200:**

```json
{
  "success": true,
  "message": "Comando ejecutado",
  "data": {
    "salida": "Filesystem      Size  Used Avail Use% Mounted on\noverlay         911G   53G  812G   7% /\n..."
  }
}
```

#### `PUT /api/asistente-ia/configuracion/{usuarioId}` (requires JWT)

Stores the OpenRouter API key (AES-encrypted in MongoDB) and the preferred model.

```bash
curl -s -X PUT https://autodeploy.kruhale.com/api/asistente-ia/configuracion/$USER_ID \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "apiKey": "<your-openrouter-key>",
    "modeloPreferido": "google/gemini-2.5-pro",
    "comandosAutoAprobados": ["df -h", "free -m", "uptime"]
  }'
```

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/servidores/{id}/backups` | GET | List the server's backups |
| `/api/servidores/{id}/backups/auto` | POST | Enable/disable automatic backups (cron on the VPS) |
| `/api/servidores/{id}/firewall` | GET | Active UFW rules |
| `/api/servidores/{id}/firewall` | POST | Add a UFW rule |
| `/api/servidores/{id}/networking` | GET | Network configuration (interfaces, DNS) |
| `/api/servidores/{id}/redirecciones` | GET / POST | nginx redirects (subdomains → internal port) |
| `/api/servidores/{id}/ssl` | GET / POST | Let's Encrypt certificate status and issuance |
| `/api/servidores/{id}/logs` | GET | Tail logs of deployed applications |
| `/api/metricas/{id}/ultima` | GET | Latest metrics snapshot (CPU, RAM, disk) |
| `/api/metricas/{id}/recolectar-ahora` | POST | Force an immediate metrics collection |

### WebSocket

| Endpoint | Client → server message | Server → client message |
|----------|----------------------------|----------------------------|
| `/ws/terminal?servidorId=X` | Text the user types in xterm.js | Remote shell output |
| `/ws/metricas?servidorId=X` | (empty, handshake only) | JSON with CPU/RAM/disk every 30 s |
| `/ws/notificaciones/{usuarioId}` | (empty) | `Notificacion` JSON whenever something happens |

Connection example from JavaScript:

```javascript
const ws = new WebSocket(`wss://${location.host}/ws/metricas?servidorId=${id}`);
ws.onmessage = (e) => console.log(JSON.parse(e.data));
```

## Administrative endpoints (ADMIN role)

Endpoints under `/api/usuarios/admin/**` are protected with `@PreAuthorize("hasRole('ADMIN')")`. A JWT whose `rol` claim is not `ADMIN` receives **HTTP 403**.

#### `GET /api/usuarios/admin/todos`

Lists all registered users. Administrators only.

```bash
curl -s -H "Authorization: Bearer $TOKEN_ADMIN" \
  https://autodeploy.kruhale.com/api/usuarios/admin/todos | jq
```

```json
{
  "success": true,
  "message": "OK",
  "data": [
    { "id": "6a0a...", "email": "demo@test.com", "rol": "USUARIO", "plan": "free" },
    { "id": "6a0b...", "email": "admin@autodeploy.dev", "rol": "ADMIN", "plan": "business" }
  ]
}
```

#### `PUT /api/usuarios/admin/{id}/rol`

Changes a user's role. Body: `{ "rol": "ADMIN" }` or `{ "rol": "USUARIO" }`.

```bash
curl -s -X PUT \
  -H "Authorization: Bearer $TOKEN_ADMIN" \
  -H "Content-Type: application/json" \
  -d '{"rol":"ADMIN"}' \
  https://autodeploy.kruhale.com/api/usuarios/admin/6a0a.../rol | jq
```

**Errors:** 400 if the role is not `USUARIO` or `ADMIN`. 403 if the requester is not ADMIN. 404 if the user does not exist.

#### `DELETE /api/usuarios/admin/{id}`

Deletes a user by ID (administrative action).

```bash
curl -s -X DELETE \
  -H "Authorization: Bearer $TOKEN_ADMIN" \
  -o /dev/null -w "HTTP %{http_code}\n" \
  https://autodeploy.kruhale.com/api/usuarios/admin/6a0a...
# HTTP 204
```

## Common errors and how to avoid them

| Symptom | Cause | Fix |
|---------|-------|----------|
| 403 on everything | Missing `Authorization: Bearer` or expired token | Log in again |
| 401 with a token | Token signed with a different `JWT_SECRET` | Check `AUTODEPLOY_JWT_SECRET` in the server's `.env` |
| 413 on `/api/deploy/zip` | `client_max_body_size` < ZIP size | Raise the value in `autodeploy/nginx.conf` |
| WebSocket fails with 502 | nginx is not proxying `/ws/` with `Upgrade` | It ships preconfigured; verify nginx started cleanly |
| `data` always `null` in the frontend | Reading `respuesta` instead of `respuesta.data` | `ApiResponse<T>` pattern: extract `.data` |
